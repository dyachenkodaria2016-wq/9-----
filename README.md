# Інтерактивний курс: Бази даних — зв’язки між таблицями (9 клас)

## Склад архіву
- `index.html` — повний автономний навчальний модуль українською мовою.
- `README.md` — інструкція для запуску та публікації на GitHub Pages.

## Запуск локально
1. Розпакуйте архів.
2. Відкрийте `index.html` у сучасному браузері (Chrome, Edge, Firefox).
3. Натисніть «Профіль учня» та введіть ПІБ і клас.
4. Опрацюйте Урок 1 і Урок 2 окремо.
5. Після тесту натисніть «Згенерувати звіт». Звіт завантажується як HTML; його можна відкрити в браузері та надрукувати / зберегти у PDF.

## Публікація на GitHub Pages
1. Створіть репозиторій, наприклад `access-relationships-grade9`.
2. Завантажте `index.html` у корінь репозиторію.
3. Відкрийте **Settings → Pages**.
4. У розділі Build and deployment виберіть **Deploy from a branch**.
5. Оберіть гілку `main` і папку `/ (root)`, натисніть Save.
6. Після публікації відкрийте адресу GitHub Pages, яку покаже GitHub.

## Важливо про Microsoft Access
Це навчальний вебмодуль-супровід, а не емулятор Microsoft Access і не засіб керування файлом `.accdb`.
Симулятори тренують логіку ключів, типів зв’язків, сумісність типів і послідовність дій. Реальні таблиці та зв’язки учні створюють у встановленій програмі Microsoft Access.
Назви команд можуть трохи відрізнятися залежно від версії та мови інтерфейсу Access.

## Звіти
Після завершення кожного тесту формується окремий звіт з ПІБ, класом, датою, номером спроби, балом за 12-бальною шкалою, кількістю правильних відповідей, помилками та часом. Самі формулювання тестових завдань у звіт не дублюються.
Для PDF: відкрийте завантажений HTML-звіт і натисніть Ctrl+P → «Зберегти як PDF».

## Технічні особливості
- Один HTML-файл, без зовнішніх бібліотек і CDN.
- Працює офлайн після завантаження.
- Адаптивний інтерфейс для комп’ютерів, планшетів і смартфонів.
- Drag & Drop має резервний режим: натискання картки, потім цільової зони.
- Дані учня зберігаються лише в поточній вкладці браузера під час роботи; автоматичного надсилання вчителю немає.
